# rishikeshpaudel.com.np

Personal academic website of Rishikesh Paudel. Plain HTML and CSS, no build step and no JavaScript.

- `index.html`: the page
- `style.css`: styles
- `assets/`: portrait, CV (PDF) and figures
- `robots.txt`: keeps AI crawlers out; the page itself is marked noindex

Hosted on GitHub Pages with the custom domain in `CNAME`.
